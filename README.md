# Traffic Edit — Affiliate Network MVP

Performance affiliate network connecting advertisers with micro-publishers, creators, and traffic partners to drive measurable sales and leads.

## Included
- Landing page for Advertisers and Publishers
- Campaign marketplace demo
- CPA / CPS / CPL positioning
- Interactive campaign filters
- Campaign economics estimator
- Early-access role form
- Responsive layout

## Deploy
Static HTML/CSS/JS. Import this GitHub repository into Vercel and deploy with no build command.

## Before production
Replace demo campaign names, metrics and payouts with approved advertiser terms. Connect the early-access form to a real backend, email provider, CRM or database. Add authentication, unique tracking links, conversion callbacks/postbacks, fraud checks, approval workflow and payout logic before operating as a real affiliate network.
